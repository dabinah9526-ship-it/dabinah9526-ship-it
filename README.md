## Projects

### K-STEP

한국 여행 기록과 여행 루트를 공유하는 SNS 개인 프로젝트입니다.

- **기술:** React, Express, Oracle, JWT
- **담당:** 기획, DB 설계, API 개발, 화면 연동
- **기능:** 피드, 다중 이미지, 여행 루트, 댓글, 좋아요, 저장, 팔로우, 채팅, 알림
- 피드·이미지·여행 장소 저장 과정에 트랜잭션을 적용해 데이터가 어긋나지 않도록 처리했습니다.

[프로젝트 자세히 보기](https://github.com/dabinah9526-ship-it/react_project_kstep)

### UNIPET

쇼핑, 커뮤니티, 예약 기능을 제공하는 반려동물 통합 플랫폼 팀 프로젝트입니다.

- **기술:** Java, Spring Boot, MyBatis, MySQL, JSP
- **담당:** 쇼핑몰과 커뮤니티 기능
- **기능:** 상품 조회, 장바구니, 게시판, 댓글, 첨부파일, 금칙어 필터링
- 공백과 특수문자를 사용한 우회 표현도 인식하도록 정규식을 적용하고, 금칙어를 DB에서 관리하도록 개선했습니다.

[프로젝트 자세히 보기](https://github.com/Medo-skb/Unipet)
